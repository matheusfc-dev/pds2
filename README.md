# PDS2 - C++ Exercises

Repository with exercises developed for the **Software Design and Development 2 (PDS2)** course, implemented in C++.

## 📋 About

This repository gathers the practical exercises, assignments, and lists proposed throughout the course, organized by topic. The goal is to consolidate learning of object-oriented programming concepts and data structures in C++.

## 📚 Topics covered

- [ ] Basic C++ syntax (variables, types, input/output)
- [ ] Conditional and loop structures
- [ ] Functions and parameter passing
- [ ] Arrays and matrices
- [ ] Pointers and dynamic memory allocation
- [ ] Structs
- [ ] Object-Oriented Programming (classes, encapsulation)
- [ ] Inheritance and polymorphism
- [ ] Operator overloading
- [ ] Templates
- [ ] Data structures (lists, stacks, queues, trees)
- [ ] Exception handling

## 🛠️ How to compile and run

Each exercise can be compiled individually using `g++`:

```bash
g++ -std=c++17 -Wall -o exercise01 exercise01.cpp
./exercise01
```

## 💻 Requirements

- A C++ compiler (g++, clang++, or similar) with C++11 support or higher
